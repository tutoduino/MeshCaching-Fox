# About MeshCaching-Fox

MeshCaching-Fox is the Fox's firmware based on MeshCore repeater for MeshCaching https://tutoduino.fr/en/articles/organize-meshcaching/ activities

## Build MeshCaching-Fox firmware
Clone the repository:
    $ git clone https://github.com/tutoduino/MeshCaching-Fox.git
Enter the project directory:
    $ cd MeshCaching-Fox
